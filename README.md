# English ↔ French Phrase Trainer

A simple browser-based English/French phrase practice app built with HTML, CSS, and JavaScript.

The app displays phrases in either English or French and asks the user to provide the translation. It tracks attempts, correct and incorrect answers, and shows the results during practice.

## Features

- English ↔ French translation practice
- Random phrase selection
- Tracks correct and incorrect answers
- Tracks number of attempts
- Shows correct answers for mistakes
- Built-in vocabulary loaded from JSON
- Simple, lightweight frontend with no backend required

## Getting Started

Clone or download the project and open `index.html` in a browser.

For local development, a simple local web server is recommended because the app loads vocabulary from a JSON file.
